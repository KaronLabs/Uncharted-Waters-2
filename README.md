# 대항해시대 2 한글판: 다시 항해하는 기록

> 항구는 열렸습니다. Windows 11 신형 선박은 아직 조선소에 있습니다.

이 저장소의 주인공은 **대항해시대 2 한글 DOS판**입니다. 게임 자료를 보존하고, 파일 형식과 데이터를 근거로 분석하며, 그 결과를 바탕으로 Windows 11에서 쓸 수 있는 새 도구와 작품을 만들어 가고 있습니다. 영어판을 다룬 훌륭한 선행 연구가 있지만, 이곳에서는 한글 대사와 한글판 고유 자료부터 살펴봅니다.

## 지금 어디까지 왔나요?

| 항목 | 현재 상태 |
| --- | --- |
| 원본 게임 | 한글 DOS판 자료와 DOSBox 0.74 실행 환경을 보존했습니다. |
| LS11 자료 | `KAO.LZW`의 256개 엔트리 디코드와 BMP 초상화 256장 렌더를 검증 기록에 남겼습니다. |
| 한글 대사·세계 데이터 | 추출과 교차 검증을 진행할 차례입니다. |
| Windows 11 재창조판 | 제작 중입니다. 완성된 Windows 네이티브 게임을 제공하는 단계는 아닙니다. |

모르는 바이트는 바다에 던지지 않고 파일명과 오프셋을 적어 둡니다. SF6 분석에서 익힌 **원본 근거 보존 → 작은 재현 → 검증 게이트 → 결과 기록**을 이 항해에도 적용할 계획입니다. 확인된 사실과 추정은 [작업 기록](uw2-ssot.md)에서 구분합니다.

## 원본 DOS판 실행

Windows에서 이 저장소의 루트로 이동해 `run.bat`을 실행하세요. 함께 보존된 DOSBox 0.74가 `C HDD`를 C 드라이브로 연결하고 게임 실행 명령을 입력합니다. `run.bat`은 현재 디렉터리를 기준으로 `DOSBox-0.74`로 이동하므로 **저장소 루트에서 실행**하는 편이 안전합니다.

```powershell
cd <저장소를_복제한_폴더>
.\run.bat
```

이 안내는 원본 DOS판용입니다. Windows 11용 재창조판의 설치 안내가 아닙니다.

## 항해 지도

| 경로 | 들어 있는 것 |
| --- | --- |
| `C HDD/` | 한글판 게임 실행 파일, 대사·세계·그림 자료와 함께 보존된 옛 도구 |
| `DOSBox-0.74/` | 원본 게임을 실행하는 DOSBox 환경과 설정 |
| `work/` | 한글판 디코딩 스크립트, 원시 추출물, 초상화 등 현재 작업 결과 |
| `research/` | [Johan Li의 선행 연구](https://github.com/JohanLi/uncharted-waters-2-research)를 바탕으로 작업 중인 분석 파일과 현재 산출물 |
| `archives/` | 공개 시점의 `research/.git` 및 `research/node_modules` 전체 ZIP과 파일·해시 목록 |
| `uw2-ssot.md` | 확인된 분석 결과, 미해결 문제, 다음 검증 단계 |

`research/raw/`는 작업 컴퓨터에서는 `work/raw-korean/`을 가리키는 접합점입니다. 공개 스냅샷에서는 같은 한글판 자료를 **실제 파일로 복사**했습니다. 영문판 자료는 `work/raw-english/`에서 따로 확인할 수 있습니다.

`research/.git`과 `research/node_modules`는 원래 작업 컴퓨터에서 그대로 유지하고, 공개 저장소에는 ZIP으로 보존했습니다. 새 복제본에서 선행 연구의 독립 Git 이력이나 당시 의존성 상태가 필요할 때 `archives/`의 압축본과 [파일 목록](archives/MANIFEST.json)을 확인하세요. 일반적인 연구 스크립트 실행에는 `research/package.json`에 적힌 Node.js와 pnpm 환경을 사용하시면 됩니다.

- `research/`의 선행 연구는 [Johan Li의 프로젝트](https://github.com/JohanLi/uncharted-waters-2-research)에서 출발했습니다. 해당 코드의 MIT 고지는 [`research/LICENSE`](research/LICENSE)에 있습니다.
- `DOSBox-0.74/`에는 별도로 배포된 DOSBox 실행 환경이 들어 있습니다.

공개된 자료를 살펴보실 때에는 각 원저작물과 라이선스 고지를 함께 확인해 주세요. 이 저장소의 공개가 게임 원작이나 선행 연구의 권리를 새로 부여한다는 뜻은 아닙니다.

한글판 항해는 계속됩니다. 다음 정박지는 대사, 세계 데이터, 그리고 **검증 가능한** Windows 11 결과물입니다.
