# 카타리나 Windows 인수 후보: 주인공 공통 창 제목

이 문서는 **카타리나 후보의 제목 수정본**에 대한 다운로드·검증 안내입니다. 조안편 정식판(`v0.3.1`)과 GitHub Latest는 그대로이며, 카타리나 전편 사용자 인수는 아직 끝나지 않았습니다.

## 내려받기

- [사전 릴리스](https://github.com/KaronLabs/Uncharted-Waters-2/releases/tag/catalina-candidate-20261108-562de4d-title)
- [Windows 11 x64 휴대용 EXE](https://github.com/KaronLabs/Uncharted-Waters-2/releases/download/catalina-candidate-20261108-562de4d-title/UW2-Catalina-Korean-title-562de4d.exe)
- 파일 크기: **109,878,543 bytes**
- SHA256: **`e6ea779ac99f925c20b1a7967e224661f5cb6cd2a13a3a8cfa209a2a2ec1bc56`**
- 제목 수정 소스 커밋: `562de4d0da290a58b8a3ed9d52c81711811d618a`

설치 없이 EXE를 실행합니다. 코드 서명이 없으므로 Windows 게시자 확인 경고가 나타날 수 있습니다. 현재 기본 슬롯 경로는 `%APPDATA%\UW2-QCaine-Preview\slots`이며, 이번 제목 검사에는 저장이 필요하지 않습니다. 기존 슬롯로 플레이를 이어가려면 게임을 종료한 뒤 해당 `slots` 폴더를 먼저 복사해 두십시오.

## 무엇을 고쳤고 무엇을 확인했나

Electron의 초기 창 제목과 웹 문서의 한국어·중국어 제목에서 조안 전용 접미사를 제거했습니다. 조안과 카타리나가 같은 실행본에 있으므로 제목은 주인공 공통 이름을 사용합니다. 게임 상태·함선 이름·슬롯 형식은 바꾸지 않았습니다.

| 언어 | 정상 창 제목 |
| --- | --- |
| 한국어 | `대항해시대 II` |
| 简体中文 | `大航海时代II` |
| English | `Uncharted Waters: New Horizons` |

제목 변경을 포함한 소스에서 `npm run verify`가 종료 코드 0으로 통과했습니다(Jest **126 suites / 1,103 tests**, Windows 슬롯 저장 검사 **4/4**, 타입 검사·lint·웹 빌드 포함). 별도 `npx tsc --noEmit -p tests/tsconfig.json`도 종료 코드 0입니다. 제목 관련 headless Chrome 현지화 검사 **6/6**과 `forge-loop` 독립 검토 **PASS / NOT GUILTY**를 확인했습니다. 첫 Cypress 실행 래퍼는 테스트 6개 통과 뒤 `wmic.exe` 정리 오류로 종료 코드 1이 났고, 같은 spec을 직접 재실행해 종료 코드 0을 확인했습니다.

위 SHA의 **새 휴대용 EXE**는 별도 시험 프로필·슬롯 폴더로 실행했습니다. Windows 창에서 한국어 제목, 카타리나 새 게임의 세빌리아 시작과 제목 유지, 중국어·영어 전환 후 각 제목을 관찰했습니다. 시험 슬롯 경로가 격리 폴더를 가리키는 것도 화면에서 확인했으며 시험 창만 종료했습니다. 이 실험은 카타리나 전편 완주 검증이 아닙니다.

이전 후보(`fe549e03e31e1fd3bdd84e7824291f75360f8ded23f60ae07eaae945526edccc`)의 [D1~D6·D8 실행 기록](completion-report.md)은 당시 EXE에 대한 기록입니다. 새 EXE의 전체 여정 결과로 합산하지 않습니다. 원래 미션의 실제 OS IME 조선소 입력 전체 절차와 Windows 150% 화면(`D7/E4/E5`), 형님의 새 게임부터 엔딩까지 수동 전편 플레이(`U1~U8`)도 완료로 표시하지 않습니다. `Rebellion`은 현재 저장되는 카타리나 함선 고유명으로, 이번 제목 수정에서 이름을 자동 변경하지 않았습니다.

| 게임 종료 후 다시 실행 | 선택한 언어의 공통 제목이 나타나며 이전 게임을 저장하지 않았다면 새 슬롯 파일이 생기지 않음 |
