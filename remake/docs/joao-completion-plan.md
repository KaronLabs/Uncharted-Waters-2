## 작업과 소유권

1. 항해: 칼리컷 접근·입항 실패를 원본 로그와 비교하여 최소 재현. 테스트 도우미/제품 중 실제 원인에만 수정. 이전 계측의 콜백 누적을 배제한다.
2. 조안: 리스본·첫 항해·중반·마사와·후반·엔딩 대사 및 일지 번역, 한국어 이름 삽입.
3. 공용 UI: 교역·선원·전투·보급·저장·오류·날짜·시각·소개·접근성, 입력 조합 및 한글 레이아웃.
4. 명칭: 원작 인명·항구·함선·물품·발견지 및 설명 대조. 사용자 입력명은 보존한다.
5. 통합 책임자: 사전 통합, 전수 누락·토큰 검사, 한국어 실제 EXE 완주 도구, 각 작업 독립 검토, 배포.

원문 키·스토리 ID·Save v8 데이터 ID는 유지한다. 사전 파일은 작업별로 분리하며 catalogs.ts 최종 통합은 책임자만 수행한다. 의존성 변경 없이 기존 도구를 사용한다.

## 검증 및 완료 기준

- 실패를 먼저 재현하고 수정 후 회귀·음성 검사를 수행한다. 칼리컷 반경 확대, 순간이동, 시간 제한 증가, 진행·승리 주입으로 통과시키지 않는다.
- 조안과 공용 원문 수집기의 한국어 누락/치환 토큰 불일치 0. 실제 화면의 영문 fallback과 한글 잘림 검사.
- 최종 EXE의 신규 조안으로 리스본→첫 항해→중반→마사와→칼리컷→나가사키→후반→아마존 승리→리스본 자택 엔딩.
- 칼리컷 이전 장시간 실패 조건을 중간 재시작으로 회피하지 않는다. 이후 실제 Windows 파일 슬롯 저장·완전 종료·재실행·복원·후속 진행을 같은 저장 계보로 확인한다.
- 엔딩 후 재방문/재실행에서 중복 보상·상태 손실이 없다. 실행본 SHA-256, 입력·저장·스크린샷·종료 코드를 증거로 남긴다.
- 모든 필수 게이트와 독립 검토 통과 후에만 조안편 정식 릴리스를 게시하고 README 기본 다운로드를 변경한다.

계획 추정은 24~48시간이며, 후반 신규 차단 발견 시 48~72시간이다. 완료 주장은 실제 결과를 따르며 시간이나 테스트 개수로 대체하지 않는다.
