# 조안편 v0.3.0 — 사용자 인수 완료

## 완료 근거와 범위

2026-10-23 사용자가 배포 EXE를 사용한 뒤 조안편을 완료로 처리하도록 지시했고, main 반영과 GitHub Latest 정식 배포를 승인했습니다. 현재 상태는 **조안편 사용자 인수 완료**입니다.

- 완료 표시: 조안편 한국어 Windows 배포본.
- 미완료: 나머지 다섯 주인공의 한글화·완주. 원본 DOS 저장 상태의 완전한 재개는 제공하지 않습니다.
- 이번 변경: 사용자 인수 상태·README·인계 안내를 반영하고 기존 소스와 동일 EXE를 정식 배포.

사용자 인수 확인과 자동 검사 기록은 구분합니다. 기존 자동 전편 여정의 통과 기록, 실제 Windows IME 조합·오프라인 글꼴·긴 대사 전체의 독립 측정은 이번 배포 전환에서 새로 생성하지 않았습니다. 이전 검사 원문과 실패 기록은 그대로 보존합니다.

## 보존된 검사 기록

[후보 인수 보고서](joao-candidate-handoff-2026-10-23.md), [원격 증거 목록](handoff/2026-10-23/README.md), [63개 파일 무결성 목록](handoff/2026-10-23/candidate-5e2487a-manifest.json)을 보존합니다. manifest의 인수 대기 표시는 수집 시점 상태이며 현재 사용자 인수 상태는 이 문서를 따릅니다.

제품 소스 기준 Jest 121 suites / 1062 tests와 데스크톱 59 tests, 후속 도구 6a747a1946904ec5ae21a5ab2ed5b53a408fa434 기준 데스크톱 61 tests는 각 당시 로그입니다. 후보 게시 때 별도 clone+LFS의 63개 파일과 릴리스 자산 3개의 해시를 대조했고 manifest 변조 거절도 확인했습니다. 이 정식 배포 전환에서는 문서·배포 링크와 동일 EXE 해시를 검사합니다.

빌드 종료 0은 당시 세션 기록에 있으며 별도 빌드 stdout 파일은 보존되지 않았습니다. 과거 실패·진단 저장 및 모의 검사를 전편 정상 플레이 기록으로 합산하지 않습니다.

## 실행과 저장

Windows 11 x64에서 EXE를 직접 실행하고 시스템에서 조안·한국어 새 게임을 선택하십시오. 마을 W/A/S/D 이동과 건물 문 진입, 해상 W/A/S/D 침로 지정과 항구 근처 E 입항을 사용합니다. 조작·원작 공략 링크는 [실행 안내](../README.md)에 있습니다.

저장 폴더는 %APPDATA%\UW2-QCaine-Preview\slots입니다. 기존 데이터와 경로를 공유하므로 게임 종료 후 폴더를 복사해 백업하고 기존 슬롯을 보존하십시오.
